# GCam V45.96

面向 GRBL 三轴 CNC 的桌面 CAM。此发布提供 Windows x64 便携程序、对应源码快照和第三方许可资料。原有开发仓库及其历史不在本次公开范围内。

主要组件：OpenCASCADE 几何处理、FreeCAD libarea 与 Clipper2 的二维加工几何、OpenCAMLib、FreeCAD Adaptive2d 自适应清料，以及 Candle 控制相关代码。项目记录显示 v45.56 加入双面累计去料、v45.78 引入 Adaptive2d，v45.96 更名 GCam。这是项目变更记录摘要，不是独立验证的全部开发历史。

## 使用
解压完整 Windows 包到可写目录，运行 GCam.exe，不要只复制 EXE。发布包不携带个人设置、设备连接、API Key 或 CAD 项目。AI 云服务需自行配置，语音模型另受其随附许可约束。

## 验证范围与安全
本次净化包在隔离目录成功以状态模式启动，返回 V45.96 和空项目；便携 Python 的 OCP、VTK 导入通过；9项运行辅助脚本与对应源码哈希一致。未进行完整功能回归、真实云模型调用或实体切削验证。加工前必须人工核对刀路、装夹、行程、刀具和进给；先仿真和安全空运行，不得据此发布将其视为无人值守加工保证。

## 从模型到加工准备
- 模型与工序：导入 STL、STEP、3MF，设置毛坯、刀具和工序，组织加工步骤。
- 刀路与预览：二维轮廓/型腔、三维相关刀路、Adaptive2d 自适应清料，刀路预览与减材仿真；支持范围取决于零件与工序组合。
- 输出与控制：生成 G 代码，结合 GRBL 与 Candle 相关控制功能进行加工准备与操作。
- AI 辅助：提供 OpenAI、DeepSeek（该版本预设模型字符串 deepseek-flash）与 Ollama 接入选项，辅助选择刀具、调整参数、组织工序和生成候选刀路。服务可用性和模型名由服务商决定；不保证所有当前服务接口可用。
- 本地语音：SenseVoiceSmall 与 sherpa-onnx 提供本地识别入口。云端AI与本地语音不是同一项服务，云端需自行配置。

AI用于辅助表达和操作，最终几何与刀路由程序算法处理。它不替代专业工艺判断，发布验证未覆盖实际切削安全。
